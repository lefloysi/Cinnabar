Hello! This is my first specification. I would be extremly happy if you gave me any feedback on literally anything. This is also my first \LaTeX\ document.

This document covers the Cinnabar programming language. Cinnabar is a C++ inspired high level language that compiles to native machine code.

It tries to create an enviroment that is similar to C++, but different in many ways.

\bigskip
These include but are not limited to:

\para[Better Defaults] eg. explicit / nodiscard by default
\para[Better Moves] eg. destructive moves / no implicit copy 
\para[Zero-Cost Safety] eg. bounds checking eliminated when provable
\para[Built-In Error handling] I don't know how this will work yet. It is a work in progress.
